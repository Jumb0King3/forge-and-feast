# Forge and Feast 2.6.1

Retort charcoal yield now twice the base game

  - Base game charcoal pits give about 5.5 charcoal per 32 firewood, so the
    retort now gives about double that (about 10.7 per 32).
  - Firewood: 3 firewood makes 1 charcoal (was 2).
  - Logs: 3 logs make 4 charcoal (was 1 for 1). A log is 4 firewood, so this is
    the same 3 to 1 rate.
  - Batch time and coke are unchanged.
